## Description

A <strong> PARKING </strong> booking application that includes front-end and back-end parts

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
